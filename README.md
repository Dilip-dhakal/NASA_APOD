# Cosmic Canvas

Cosmic Canvas is a basic website where users can view NASA's Astronomy Picture of the Day (APOD). This web app basically fetches data/images from NASA's public API every time a user visits or refreshes the site.

## Technologies

* **Vite with React** for fetching data from NASA's public API.
* **HTML and CSS** for the basic layout and styling.
* **TypeScript** for type safety.
