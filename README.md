#Cosmic Canvas
Cosmic Canvas is a basic website where user can have the Nasa's Astronomy Picture Of The Day(APOD). This web app basically fetches data/images from the public API of NASA everytime user visits or refreshs the site.

**Technologies**
VITE with React for fetching the fata from Nasa's Public Api
HTMl and CSS for basic layout and stylying
TypeScript for typesafety
