NASA APOD(Astronomy Picture Of The Day) is a basic website which is a fun hack club project where user can have the Nasa's Astronomy Picture Of The Day(APOD). This web app basically fetches data from the public API of NASA everytime user visits or refreshs the site.

This project is a frontend only and uses 
VITE with React for fetching the fata from Nasa's Public Api
HTMl and CSS for basic layout and stylying
TypeScript for typeSafety
